ヘルゴルフHERUGOLF

Nikoli 的「逻辑高尔夫」。盘面只给三种东西：带数字的球、H（球洞）、池。

  1. R1 每颗球都走进一个 H，每个 H 恰好落一球。
  2. R2 每动一次沿上下左右走「球里的数字」那么多个格，走完减 1 ⇒ 动长严格 k, k−1, …。
  3. R3 线不许穿过别的球、不许穿过 H（停在上面不算）、不许自交；线两两不许交叉或重叠。
  4. R4 不许出界；不许停在池上，但可以穿过。

点一颗球选中它，再点目标格（或直接滑动一个方向）走一动；U 撤销那一动。出货的每一盘都由独立计数器数过唯一解、由铅笔零猜测推到底。

玩法与键位

  1. R1 一球一洞：所有球进 H，每个 H 只落一球。
  2. R2 一动比一动短：k, k−1, k−2, …，方向每动可换。
  3. R3 每格最多被一条线通过：不许穿球、穿 H、自交、互交。
  4. R4 不出界；可穿池，不可停池。
键位
Enter / Space开局；赢了则下一局（不参与暂停）
P暂停 / 继续（暂停期间仿真一步都不推进）
R重开本盘（时钟、粒子、玩家线、撤销栈全复位）
N下一局（seed 自增，不是按日期抽）
U撤销上一动
G提示：拿铅笔那条「单走法」，不替你画答案
